# Paper Summaries

This document summarizes the papers stored in the `paper/` directory.

## 1. 2204.11192v1.pdf
RedMulE is a compact FP16 matrix multiplication accelerator designed for adaptive deep learning on ultra-low-power RISC-V SoCs. It targets extreme-edge workloads by integrating with a PULP-based cluster and delivering high throughput and energy efficiency. The design claims up to 4.65× higher energy efficiency and 22× speedup versus software on eight RISC-V cores.

## 2. 3489517.3530432.pdf
SCAIE-V presents an open-source scalable interface for RISC-V ISA extensions that supports custom control flow, decoupled execution, multi-cycle instructions, and memory transactions. It aims to reduce engineering effort and improve portability for custom instruction extensions across different processor cores.

## 3. Analog_artificial_intelligence_hardware_for_neural.pdf
This review covers analog AI hardware for neural networks, focusing on analog VLSI design approaches such as in-memory computing, current-mode circuits, switched-capacitor techniques, and OTA-based designs. It discusses key challenges including process variation, crossbar scalability, precision-linearity trade-offs, mixed-signal interfaces, and edge deployment considerations.

## 4. Automatic_Microarchitecture_Aware_Custom_Instruction_Design_for.pdf
CIDRE is a tool for automatic microarchitecture-aware custom instruction design for RISC-V processors. It analyzes application hotspots, proposes custom instructions with nML descriptions, and enables accurate cost-benefit evaluation. The paper reports benchmark speedups up to 2.47× with less than 24% area increase.
